. Naming conventions to follow for Pytest Tests
    file name and test name shuld statrts with 'test_' or ends with '_test'  

. Running Pytests from command Line 

    To run all test in pytest folder : pytest --> for more detailed use: pytest -v --> for printing console use : pytest -v -s 

    Running selected test file : pytest {filename}.py -v -s   

    Running selected test Methods based on matching keywords: pytest -k card -v

    we can mark (tag) test @pytest.mark.smoke : pytest -m smoke -v

    we can skip test @pytest.mark.skip :  pytest test_bank_account.py -v

 . Fixtures --> refer fixture.py file--> setup - runs before actual test and Yield act as teardown --> runs after the test completed

. How Fixtures can be configured in Conftest file for better readability --> 
    conftest file to generalize fixture and make it available for all testcases in all file.
    run: pytest test_fixture.py -v -s

. Different scopes of fixtures and their related annotations to setup Pre and Post conditions of the Test --> 
    this like runing setup only once before all the test case and teardown after all test cases. --> so we need to organise test cases inside class. 
    in class we can pass the self parameter with the fixture --> @pytes.mark.usefixture("setup")
